# Korean Working Language

이 프로젝트의 기본 작업 언어는 한국어다.

## 한국어로 작성한다

- 제품 기획 문서
- 요구사항 문서
- ADR 등 의사결정 문서
- 이슈 설명
- PR 설명
- 코드 리뷰 코멘트
- Agent의 작업 요약
- 사용자에게 전달하는 작업 결과

## 영어로 작성한다

- 코드 식별자
- 파일명과 디렉터리명
- npm script 이름
- 브랜치 이름
- 패키지명
- 외부 API 명세와 직접 맞닿는 값
- 테스트 이름 중 코드 동작을 짧게 설명하는 문장

## 영어를 유지한다

- 프레임워크, 라이브러리, 도구의 공식 용어
- 에러 메시지 원문
- 외부 문서나 스펙에서 가져온 고유 표현
- Conventional Commits의 `type` 값

## 판단 기준

사람 사이의 의사소통은 한국어를 우선한다.

코드, 도구, 생태계와 직접 연결되는 이름은 영어를 유지한다.
