# Project Brief

이 문서는 Agent가 기본 컨텍스트로 먼저 읽는 짧은 프로젝트 요약이다. 상세 내용은 각 reference 문서를 확인한다.

## 프로젝트

Todo App은 일반 사용자를 위한 최소 기능 체크리스트형 Todo 앱이다.

이 저장소의 목적은 단순한 Todo 기능 구현이 아니라, AI Agent와 함께 기획, Figma 디자인, TDD 기반 개발, 검증, 기록을 작은 task 단위로 반복하는 방법을 실험하는 것이다.

## 제품 목표

사용자가 앱을 열자마자 할 일을 빠르게 추가하고, 체크리스트처럼 완료 처리하며, 아직 남은 일을 한눈에 볼 수 있게 한다.

## 대상 사용자

개인 할 일을 간단한 체크리스트로 관리하고 싶은 일반 사용자.

## MVP 범위

- 할 일 추가
- 할 일 완료 처리와 완료 취소
- 할 일 삭제
- 남은 할 일 개수 표시
- 빈 상태 표시
- 완료된 할 일과 남은 할 일의 시각적 구분

## 승인된 확장 범위

- 각 할 일에 선택 메모 추가
- 생성된 할 일에서 메모 추가, 수정, 비우기
- 메모가 있는 할 일은 제목 아래에 2줄까지 표시
- 메모 편집은 한 번에 하나의 할 일만 열기

## 제외 범위

- 계정
- 로그인
- 서버 동기화
- 마감일
- 우선순위
- 태그
- 검색
- 알림
- 반복 일정
- 협업 기능

## 성공 기준

- 사용자는 5초 안에 첫 할 일을 추가할 수 있다.
- 사용자는 별도 설명 없이 할 일을 완료 처리할 수 있다.
- 사용자는 남은 할 일 개수를 바로 확인할 수 있다.
- 완료된 할 일과 남은 할 일이 명확히 구분된다.
- 삭제 동작은 사용자가 삭제 의미를 명확히 이해할 수 있어야 한다.
- 사용자는 할 일 추가 속도를 해치지 않고 필요한 항목에만 메모를 남길 수 있다.

## Agent Harness 목표

- 사용자의 자연어 아이디어를 바로 구현하지 않고 먼저 제품 초안으로 정리한다.
- 승인된 초안만 문서와 implementation plan으로 내린다.
- Agent가 모든 문서를 매번 읽지 않도록 짧은 운영 문서를 기본 컨텍스트로 사용한다.
- 한 번에 하나의 task만 실행하고 검증 가능한 상태로 기록한다.
