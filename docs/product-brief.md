# 제품 기획서

## 제품명

Todo App

## 제품 방향

일반 사용자를 위한 최소 기능 체크리스트형 Todo 앱.

이 앱은 많은 기능을 제공하는 생산성 도구가 아니라, 사용자가 할 일을 빠르게 적고 완료 여부를 명확히 확인할 수 있는 작은 체크리스트를 목표로 한다.

## 대상 사용자

개인 할 일을 간단한 체크리스트로 관리하고 싶은 일반 사용자.

## 문제 정의

사용자는 복잡한 일정 관리나 프로젝트 관리 도구까지는 필요하지 않지만, 지금 해야 할 일을 빠르게 적고 완료 여부를 명확히 확인할 수 있는 공간이 필요하다.

## 목표

사용자가 앱을 열자마자 할 일을 추가하고, 체크리스트처럼 완료 처리하며, 아직 남은 일을 한눈에 볼 수 있게 한다.

## MVP 범위

- 할 일 추가
- 할 일 완료 처리
- 할 일 완료 취소
- 할 일 삭제
- 남은 할 일 개수 확인
- 완료된 할 일과 남은 할 일의 시각적 구분

## 승인된 확장 범위

MVP 완료 이후 각 할 일에 선택 메모를 남길 수 있게 확장한다.

메모 기능은 할 일 추가 속도를 해치지 않기 위해 생성 시점의 입력 폼에는 포함하지 않는다. 사용자는 할 일을 먼저 만든 뒤, 필요한 항목에서 메모를 추가하거나 수정하거나 비울 수 있다.

메모는 할 일의 부가 정보로 다룬다.

- 메모는 선택 입력이다.
- 메모는 생성된 할 일 항목에서 추가한다.
- 메모가 있는 항목은 제목 아래에 메모를 2줄까지 표시한다.
- 메모 편집은 한 번에 하나의 할 일만 열린다.
- 빈 값으로 저장하면 메모가 삭제된다.
- 완료된 할 일도 메모를 볼 수 있고 수정할 수 있다.

## 완료 항목 표시 방식

완료된 할 일은 목록에서 숨기거나 별도 영역으로 옮기지 않는다.

MVP에서는 완료된 할 일을 같은 목록에 그대로 두고, 다음 방식으로 남은 할 일과 구분한다.

- 체크된 체크박스
- 낮은 강조도의 텍스트
- 필요하다면 취소선

이 방식은 사용자가 완료한 일을 계속 확인할 수 있게 하며, 완료 상태를 다시 되돌리는 동작도 단순하게 유지한다.

## 제외 범위

MVP에서는 다음 기능을 제공하지 않는다.

- 계정
- 로그인
- 서버 동기화
- 마감일
- 우선순위
- 태그
- 검색
- 알림
- 반복 일정
- 협업 기능

## 성공 기준

- 사용자는 5초 안에 첫 할 일을 추가할 수 있다.
- 사용자는 별도 설명 없이 할 일을 완료 처리할 수 있다.
- 사용자는 남은 할 일 개수를 바로 확인할 수 있다.
- 완료된 할 일과 남은 할 일이 명확히 구분된다.
- 삭제 동작은 사용자가 삭제 의미를 명확히 이해할 수 있어야 한다.
- 사용자는 필요한 할 일에만 보충 메모를 남길 수 있다.
